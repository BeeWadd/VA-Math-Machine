# Security policy

## Supported version

Only the current production version on the default branch is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not include a veteran's disability details, dependent information, or other sensitive personal information in a report.

## Data handling

VA Math Machine performs calculations locally in the browser. It has no application backend, analytics, advertising, account system, or runtime third-party requests. Entries are held in page memory and are cleared when the page is closed or refreshed.
